**Dr VPN** — простое VPN-приложение с открытым исходным кодом для Android в стиле Hiddify: одна большая кнопка подключения, карточка активной подписки и карточка выбранного сервера.

- 🌐 Сайт: [drvpn.net](https://drvpn.net/)
- 📢 Telegram-канал: [@drVPN_net](https://t.me/drVPN_net)
- 📄 Статья: [Как купить VPN-подписку + знакомство с Dr VPN](ARTICLE-ru.md)

## ✨ Возможности

- Подключение одним нажатием большой кнопки на главном экране
- Первый запуск: выбор страны (местные сайты открываются напрямую) и языка приложения
- VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, SOCKS и HTTP
- Добавление подписок и конфигов из ссылки, буфера обмена, QR-кода или файла
- Автоматический пинг серверов; показываются только рабочие (галочка — показать все)
- Флаг страны рядом с каждым сервером
- Прокси для отдельных приложений, правила маршрутизации, тёмная тема

## 📥 Скачать

Нажмите зелёную кнопку **DOWNLOAD** вверху страницы или откройте [Releases](https://github.com/DrvpnTM/app/releases/latest) и скачайте `DrVPN.apk`.

## 📱 Как пользоваться

1. Установите и откройте приложение, выберите страну и язык.
2. Нажмите **+** вверху и импортируйте ссылку подписки или конфиг (буфер обмена или QR-код).
3. Рабочие серверы появятся во вкладке **Прокси** — выберите один.
4. Вернитесь на **Главную** и нажмите большую кнопку. Зелёный цвет — подключено.

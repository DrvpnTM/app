# Dr VPN

**Dr VPN** သည် Android အတွက် ရိုးရှင်းပြီး open-source ဖြစ်သော VPN အက်ပ်ဖြစ်သည်။ Hiddify ပုံစံ ဒီဇိုင်းဖြင့် ချိတ်ဆက်ရန် ခလုတ်ကြီးတစ်ခု၊ အသုံးပြုနေသော subscription ကတ်နှင့် ရွေးထားသော server ကတ် ပါဝင်သည်။

- 🌐 ဝက်ဘ်ဆိုက်: [drvpn.net](https://drvpn.net/)
- 📢 Telegram channel: [@drVPN_net](https://t.me/drVPN_net)
- 📄 ဆောင်းပါး: [VPN subscription ဝယ်နည်း + Dr VPN မိတ်ဆက်](ARTICLE-my.md)

## ✨ လုပ်ဆောင်ချက်များ

- ပင်မစာမျက်နှာရှိ ခလုတ်ကြီးကို တစ်ချက်နှိပ်ရုံဖြင့် ချိတ်ဆက်နိုင်သည်
- ပထမဆုံးဖွင့်ချိန်တွင် နိုင်ငံ (ပြည်တွင်းဆိုက်များကို တိုက်ရိုက်ဖွင့်) နှင့် အက်ပ်ဘာသာစကား ရွေးချယ်နိုင်သည်
- VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, SOCKS, HTTP
- လင့်ခ်၊ clipboard၊ QR code သို့မဟုတ် ဖိုင်မှ subscription/config ထည့်နိုင်သည်
- Server များကို အလိုအလျောက် ping စစ်ပြီး အလုပ်လုပ်သော server များကိုသာ ပြသည် (အားလုံးပြရန် အမှန်ခြစ်ပါ)
- Server တစ်ခုစီဘေးတွင် နိုင်ငံအလံ ပြသည်
- အက်ပ်အလိုက် proxy၊ routing စည်းမျဉ်းများ၊ dark mode

## 📥 ဒေါင်းလုဒ်

ပြောင်းလဲမှုတိုင်းကို GitHub Actions က အလိုအလျောက် build လုပ်သည်- **Actions** tab → **Build Dr VPN APK** → နောက်ဆုံးအောင်မြင်သော run → **Artifacts** → `DrVPN-universal`။

> လက်ရှိ build သည် စမ်းသပ် (debug) build ဖြစ်သည်။

## 📱 အသုံးပြုနည်း

1. အက်ပ်ကို ထည့်သွင်းဖွင့်ပြီး နိုင်ငံနှင့် ဘာသာစကား ရွေးပါ။
2. အပေါ်ရှိ **+** ကိုနှိပ်ပြီး subscription လင့်ခ် သို့မဟုတ် config ကို (clipboard သို့မဟုတ် QR code မှ) ထည့်ပါ။
3. အလုပ်လုပ်သော server များ **Proxies** tab တွင် ပေါ်လာမည် — တစ်ခုရွေးပါ။
4. **Home** သို့ပြန်၍ ခလုတ်ကြီးကို နှိပ်ပါ။ အစိမ်းရောင်ဖြစ်လျှင် ချိတ်ဆက်ပြီးပါပြီ။

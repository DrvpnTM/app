# Dr VPN (دکتر وی پی ان) — خرید فیلترشکن پرسرعت و مطمئن برای اندروید

<div dir="rtl">

**خرید فیلترشکن** با **دکتر وی پی ان (Dr VPN)**؛ یک **فیلترشکن پرسرعت، امن و متن‌باز** برای اندروید که مخصوص شرایط سخت اینترنت ایران و **نت ملی** ساخته شده است. اگر به دنبال **خرید فیلترشکن مطمئن**، **خرید vpn پرسرعت** یا **خرید اشتراک فیلترشکن** هستید، دکتر وی پی ان با طراحی ساده و امکانات حرفه‌ای بهترین انتخاب شماست.

- 🌐 وب‌سایت و **خرید فیلترشکن**: [drvpn.net](https://drvpn.net/)
- 📢 کانال تلگرام: [@drVPN_net](https://t.me/drVPN_net)
- 📄 مقاله کامل: [راهنمای خرید اشتراک فیلترشکن و معرفی Dr VPN](ARTICLE-fa.md)

## چرا برای خرید فیلترشکن، دکتر وی پی ان را انتخاب کنیم؟

**خرید فیلترشکن پرسرعت** وقتی ارزش دارد که برنامه‌اش هم سریع، ساده و پایدار باشد. دکتر وی پی ان دقیقاً برای همین ساخته شده:

- **فیلترشکن پرسرعت** با پایداری بالا حتی در زمان اختلال، کاهش سرعت و قطعی اینترنت
- **فیلترشکن مخصوص نت ملی** با قابلیت پیدا کردن آی‌پی تمیز و پورت باز
- **فیلترشکن امن** با رمزنگاری قوی برای حفظ حریم خصوصی و امنیت روی وای‌فای عمومی
- **فیلترشکن اندروید سبک و بدون تبلیغ** با ظاهر ساده شبیه هیدیفای
- کاملاً **متن‌باز (Open Source)** و قابل اعتماد؛ کد در دسترس همه

## امکانات فیلترشکن دکتر وی پی ان

- اتصال با یک ضربه روی دکمه بزرگ صفحه اصلی
- انتخاب کشور و زبان در اولین اجرا (سایت‌های داخلی بدون فیلترشکن باز می‌شوند)
- تست خودکار سرعت سرورها و نمایش فقط سرورهای سالم
- نمایش پرچم کشور هر سرور برای انتخاب بهتر
- **حالت پیشرفته نت ملی**: اسکن آی‌پی تمیز و اعمال خودکار روی سرور
- پروکسی جداگانه برای هر برنامه (Per-App Proxy) و قوانین مسیریابی
- چند پوسته زیبا (ساده، نیومورفیک، گلس‌مورفیک) و حالت تیره
- پشتیبانی از فارسی، انگلیسی، چینی، روسی، عربی، اسپانیایی و…

## پشتیبانی از همه پروتکل‌های فیلترشکن

دکتر وی پی ان با انواع **کانفیگ فیلترشکن** سازگار است: **VLESS، VMess، Trojan، Shadowsocks، Hysteria2، WireGuard، SOCKS و HTTP**. سازگار با **کانفیگ v2ray**، **کانفیگ vless**، **کانفیگ vmess**، **ری‌الیتی (Reality)**، لینک اشتراک (Subscription) و **کیو‌آر کد**.

## 📥 دانلود فیلترشکن دکتر وی پی ان

فایل APK با هر تغییر به‌صورت خودکار ساخته می‌شود: تب **Actions** ← **Build Dr VPN APK** ← آخرین اجرای موفق ← بخش **Artifacts** ← فایل `DrVPN-universal`. برای نصب همیشگی، از نسخه‌های منتشرشده در بخش **Releases** استفاده کنید.

## 📱 آموزش استفاده در ۴ قدم

1. برنامه را نصب و باز کنید، کشور و زبان را انتخاب کنید.
2. لینک اشتراکی که از [drvpn.net](https://drvpn.net/) تهیه کرده‌اید را در بخش **+** وارد کنید (از کلیپ‌بورد یا کیو‌آر کد).
3. در تب **سرورها** یک سرور انتخاب کنید (سرورهای سالم خودکار تست و نمایش داده می‌شوند).
4. به تب **خانه** بروید و دکمه بزرگ اتصال را بزنید. سبز شدن یعنی متصل هستید.

## سؤالات پرتکرار درباره خرید فیلترشکن

**آیا دکتر وی پی ان رایگان است؟** خود برنامه رایگان و متن‌باز است؛ برای اتصال به کانفیگ یا اشتراک نیاز دارید که می‌توانید از [drvpn.net](https://drvpn.net/) تهیه کنید.

**بهترین فیلترشکن برای نت ملی کدام است؟** دکتر وی پی ان حالت مخصوص نت ملی دارد که آی‌پی تمیز پیدا می‌کند؛ همراه با کانفیگ مناسب، گزینه‌ای قوی برای شرایط سخت اینترنت است.

**چطور فیلترشکن بخرم؟** کافی است به [drvpn.net](https://drvpn.net/) بروید، اشتراک تهیه کنید و لینک آن را در برنامه وارد کنید.

## 🛠 ساخت از سورس

```bash
# نیازمندی‌ها: JDK 21، Android SDK (platform 37)، Android NDK 29
export NDK_HOME=/path/to/android-ndk
bash compile-hevtun.sh && cp -r libs V2rayNG/app/
curl -fsSL -o V2rayNG/app/libs/libv2ray.aar \
  https://github.com/2dust/AndroidLibXrayLite/releases/download/v26.9.9/libv2ray.aar
cd V2rayNG && ./gradlew assemblePlaystoreRelease
```

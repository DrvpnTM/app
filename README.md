## چرا برای خرید فیلترشکن، دکتر وی پی ان را انتخاب کنیم؟

**خرید فیلترشکن پرسرعت** وقتی ارزش دارد که برنامه‌اش هم سریع، ساده و پایدار باشد. دکتر وی پی ان دقیقاً برای همین ساخته شده:

- **فیلترشکن پرسرعت** با پایداری بالا حتی در زمان اختلال، کاهش سرعت و قطعی اینترنت
- **فیلترشکن مخصوص نت ملی** با قابلیت پیدا کردن آی‌پی تمیز و پورت باز
- **فیلترشکن امن** با رمزنگاری قوی برای حفظ حریم خصوصی و امنیت روی وای‌فای عمومی
- **فیلترشکن اندروید سبک و بدون تبلیغ** با ظاهر ساده شبیه هیدیفای
- کاملاً **متن‌باز (Open Source)** و قابل اعتماد؛ کد در دسترس همه

## امکانات فیلترشکن دکتر وی پی ان

- اتصال با یک ضربه روی دکمه بزرگ صفحه اصلی
- انتخاب کشور و زبان در اولین اجرا (سایت‌های داخلی بدون فیلترشکن باز می‌شوند)
- تست خودکار سرعت سرورها و نمایش فقط سرورهای سالم
- نمایش پرچم کشور هر سرور برای انتخاب بهتر
- **حالت پیشرفته نت ملی**: اسکن آی‌پی تمیز و اعمال خودکار روی سرور
- پروکسی جداگانه برای هر برنامه (Per-App Proxy) و قوانین مسیریابی
- **Aether (وارپ رایگان)**: وارپ کلودفلر مخصوص فیلترینگ شدید، با Tor و Psiphon؛ خودش آی‌پی سالم پیدا می‌کند
- چند پوسته زیبا (ساده، نیومورفیک، گلس‌مورفیک) و حالت تیره
- پشتیبانی از فارسی، انگلیسی، چینی، روسی، عربی، اسپانیایی و…

## پشتیبانی از همه پروتکل‌های فیلترشکن

دکتر وی پی ان با انواع **کانفیگ فیلترشکن** سازگار است: **VLESS، VMess، Trojan، Shadowsocks، Hysteria2، WireGuard، SOCKS و HTTP**. سازگار با **کانفیگ v2ray**، **کانفیگ vless**، **کانفیگ vmess**، **ری‌الیتی (Reality)**، لینک اشتراک (Subscription) و **کیو‌آر کد**.

**آیا دکتر وی پی ان رایگان است؟** خود برنامه رایگان و متن‌باز است؛ برای اتصال به کانفیگ یا اشتراک نیاز دارید که می‌توانید از [drvpn.net](https://drvpn.net/) تهیه کنید.

```bash
# نیازمندی‌ها: JDK 21، Android SDK (platform 37)، Android NDK 29
export NDK_HOME=/path/to/android-ndk
bash compile-hevtun.sh && cp -r libs android/app/
# هسته‌ی Xray (نسخه‌ی PattN) را برای اندروید ۷ به بالا می‌سازد؛ به Go هم نیاز دارد

bash build-core.sh
cd android && ./gradlew assemblePlaystoreRelease
```
